### Description

Remplace l'approche MSF RPC (db.import_data via msf-teamserver:55553)
par une écriture PostgreSQL directe — équivalent de `db_nmap` dans la
console MSF. msf-teamserver n'est plus requis pour l'import nmap.

- Parse nmap XML avec ElementTree (OS, services, hostnames)
- Upsert hosts sur (workspace_id, address) — préserve os_name existant
- Upsert services avec SELECT+INSERT/UPDATE pour éviter les NULL dans
  l'index unique (host_id, port, proto, name, resource)
- Lit PG_HOST/PG_PORT/PG_USER/PG_DBNAME depuis env + secret postgres_password

Résultat: 768 hosts + 482 services insérés en 5min (était 0 depuis
la mise à 0/0 de msf-teamserver)
