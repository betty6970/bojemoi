### Description

Ajout de 4 contraintes dans le prompt LLM pour éviter les commandes
systématiquement rejetées par le judge :
- NEVER sshpass (non installé) → ssh -o BatchMode=yes

- NEVER < file.txt (fichier local inexistant) → -P wordlist direct
- NEVER $(cat file) dans les args
+ exemples corrects dans le prompt (hydra, printf|nc, curl)

Réduit les rejets judge de N→0 à la source plutôt qu'en post-filter.
