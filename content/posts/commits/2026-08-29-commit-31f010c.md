### Description

- attack_models.py: Pydantic models (AttackPhase, AttackStatus,
  PhaseDecision, AttackPlan, Finding, AttackRequest, AttackResponse)
- attack_planner.py: LLM-constrained decision maker — plan_attack(),
  decide_vuln_scan(), decide_exploit(), decide_post_exploit() with
  deterministic fallbacks for each phase
- campaign_executor.py: async CampaignExecutor running as background
  task — OSINT→RECON→VULN_SCAN→EXPLOIT→POST_EXPLOIT→REPORT pipeline
  via bojemoi SDK (Nuclei, ZAP, MSF, Sliver, Dojo)
- db.py: init_attack_table() + 10 CRUD functions, attacks table with
  JSONB columns (findings, sessions, plan, phase_results, osint_profile)
- main.py: POST /attack, GET /attack/{id}, GET /attacks, DELETE
  /attack/{id} endpoints + asyncio task registry in app.state
