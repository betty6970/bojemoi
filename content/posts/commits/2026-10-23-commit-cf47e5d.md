### Description

Root cause du bug 2335-cycles : restart_openvpn() trouvait une interface tun
(même cassée) et resetait FAIL=0 sans vérifier la connectivité réelle.
Résultat : le container ne se relançait jamais, VPN mort pendant 38h.

Fixes :
- Vérification curl après chaque restart : si pas d'IP de sortie → exit 1
  (Docker relance le container proprement via restart: unless-stopped)
- Suppression des tun zombies avant restart (évite tun1/tun2 au lieu de tun0)
- ping -I $TUN_IF : force le test via le tunnel, pas une autre route
- CHECK_INTERVAL=30s (était 60s), MAX_FAIL=2 (était 3) → détection en 1 min
- Vérification curl au démarrage initial (exit 1 si pas de sortie VPN dès le début)
- Re-publish dojo-broker toutes les 5 min (10 cycles watchdog)
- HEALTHCHECK Docker --interval=30s --retries=2 --start-period=60s
