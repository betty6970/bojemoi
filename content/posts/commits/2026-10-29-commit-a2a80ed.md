### Description

PHP CLI et certains setups PHP-FPM retournent HTTP 200 (pas 500)
même pour les fatal errors OOM. Le check précédent ratait ces cas.

Nouveau comportement:
- 'Allowed memory size' dans body → OOM confirmé (quel que soit HTTP status)
- HTTP 500 + 'memory' → OOM confirmé (fallback prod PHP-FPM)
- HTTP 413 → toujours rejeté (nginx size limit, pas un OOM PHP)

Validé sur PHP 8.3.36 CLI avec memory_limit=16M : finding High émis.
