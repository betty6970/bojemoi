### Description

Par défaut Docker injecte une route 0.0.0.0/0 via 172.18.0.1 (gwbridge eth1) dans les
containers customs network. Résultat : nmap/hydra/nikto sortaient sur l'IP réelle de
meta-68 sans passer par ProtonVPN.

Fix : run_kali_command() préfixe chaque commande avec :
  route del default gw 172.18.0.1; route add default gw 10.0.9.10 dev eth0
→ tout le trafic internet passe désormais via wg-gateway (205.147.22.12).
net-tools (route) est disponible dans l'image, pas besoin de rebuilder.
