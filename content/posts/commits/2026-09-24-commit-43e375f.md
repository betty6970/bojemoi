### Description

Sources reconstruites depuis bytecode compilé (pyc) — premier versionnement.

Bugs corrigés :
- BUG-1 CRITICAL: _deploy_vm_task ne nettoyait pas la VM sur exception après
  create_vm → VMs orphelines sur XenServer. Fix: delete_vm(vm_ref, force=True)
  dans le bloc except si vm_ref est défini.
- BUG-2 HIGH: create_vm step 3 — réseau non trouvé → VM démarrait sans NIC
  (silencieux). Fix: lève XenServerError('NETWORK_NOT_FOUND').
- BUG-3 MEDIUM: _handle_xenapi_failure nullifiait _session sans logout préalable
  → fuite de sessions côté XenServer. Fix: appel _logout() avant _session=None.
