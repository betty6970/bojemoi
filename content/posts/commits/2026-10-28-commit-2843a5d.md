### Description

_generate_ollama was using /api/generate (raw completion) — the
{"tools": ["  prefix was treated as prompt text, not a prefill.
phi4 responded with nested objects instead of flat string arrays,
causing 100% LLM parse failures in decide_vuln_scan.

Fix: detect the prefill pattern (prompt ends with `{` without newline),
split into instruction + json_prefix, and use /api/chat with the prefix
as a partial assistant message. Ollama continues the JSON array directly.
Returns json_prefix + completion so callers get a complete parseable JSON.

Verified: decide_vuln_scan now resolves tools=['kali','nuclei','zap']
with valid=True on first attempt (no retries).
