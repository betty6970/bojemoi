### Description

generate_code() envoie le prompt via /api/generate Ollama — phi4 en
mode chat génère une RÉPONSE, pas une continuation de préfixe JSON.
L'ancien code parsait `full=prompt+raw` avec regex, causant des échecs
systématiques (LLM parse failure → fallback nuclei seul + 17 tags).

Fix:
- Prompt restructuré sans préfixe {"tools": [" — demande JSON complet
- Parse uniquement `raw` via json.loads sur tous les objets {} trouvés
- Fallback regex _extract_json_array sur raw si json.loads échoue
- Fallback minimal (nuclei seul) uniquement si aucun JSON valide

Test : 45.33.32.156 (ports 22+80) → tools=['nuclei','zap'],
tags=['exposure','misconfig','auth','apache'] — impacket/sliver exclus.
