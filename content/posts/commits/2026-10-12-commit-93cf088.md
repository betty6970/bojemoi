### Description

Replace 3 hardcoded tool overrides (impacket always if SMB, zap always
if web port, snmp always if port 161/RAG) with a single comprehensive
LLM call. The LLM now decides which tools to run based on the full
context: IP, OSINT (ISP/country/hostname/threat_score), open ports,
detected services, banner, and past similar findings (RAG).

- decide_vuln_scan() accepts optional osint dict for richer prompt
- max_tokens raised 80 → 150 to fit complete JSON response
- No-services fallback removed — LLM decides even without service info
- Minimal fallback (nuclei only) only when JSON is completely unparseable
- campaign_executor: _get_osint_profile() + passes osint to decide_vuln_scan
