### Description

Add -c flags to postgres command so settings survive container
recreations (previously set via ALTER SYSTEM in postgresql.auto.conf
only):
  - max_connections=200
  - idle_session_timeout=10min     (auto-close idle conns, prevents
                                    psycopg2 leak saturation)
  - idle_in_transaction_session_timeout=30s  (kill stuck transactions)
